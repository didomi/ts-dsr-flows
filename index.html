    Findings use the returned config and this page load. They are checks to try, not confirmed causes.

    Console setup checklist
    1. Flows → Publishing: confirm the organization, public API key, Flow ID, platform, and staging or production selection match this test.
    2. Flows → Regulations: attach a DSAR regulation and check country and region coverage.
    3. Flows → Privacy Widgets: check assigned widgets, the default widget, and display rules.
    4. Publish the Flow to the environment selected here, then reload. Production configs are allowlisted.
